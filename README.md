# RESIDENT EVIL: EL ÚLTIMO EXPERIMENTO

## Descripción del proyecto

**Resident Evil: El Último Experimento** es un videojuego de aventura y terror desarrollado en Java para consola.

El jugador interpreta a un policía novato que recibe una llamada de emergencia y debe investigar una misteriosa mansión abandonada en Raccoon City. Durante la aventura tendrá que explorar habitaciones, recoger objetos, resolver pruebas y enfrentarse a una peligrosa criatura.

Las decisiones tomadas durante la partida pueden cambiar el desarrollo de la historia y determinar el final.

## Características principales

- Historia interactiva con 14 escenas.
- Diferentes decisiones que modifican el desarrollo de la aventura.
- Sistema de inventario.
- Objetos: llave, tarjeta de seguridad, arma y botiquín.
- Accesos condicionados por los objetos del inventario.
- Minijuego del ahorcado.
- Cuatro desenlaces posibles.
- Validación de las opciones introducidas por el jugador.
- Pausas entre los textos para mejorar la experiencia de juego.
- Registro de experimentos mediante una matriz bidimensional.

## Tecnologías utilizadas

- Java.
- IntelliJ IDEA.

## Estructura del proyecto

El proyecto está organizado en tres clases principales:

- **Main.java:** contiene el desarrollo principal del juego, las decisiones, las escenas y los finales.
- **Jugador.java:** gestiona el inventario y los objetos del jugador.
- **Escena.java:** almacena y muestra la información de cada escena.

## Cómo ejecutar el juego

1. Descargar o clonar el repositorio.
2. Abrir el proyecto con IntelliJ IDEA.
3. Comprobar que Java está instalado.
4. Abrir el archivo `Main.java`.
5. Ejecutar el programa desde el botón Run.

## Objetivo del proyecto

El objetivo es desarrollar una aventura interactiva aplicando los conocimientos de programación en Java, como condicionales, bucles, métodos, clases, objetos, matrices y validación de datos.
